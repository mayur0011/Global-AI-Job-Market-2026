Global AI Job Market 2026

An end-to-end Data Analytics project that analyzes the global AI job market, salary trends, job openings, and AI specialization demand.

Tools & Technologies

- Python
- SQL / MySQL
- Excel
- Power BI
- Streamlit
- Pandas and NumPy

Project Objectives

- Analyze global AI job opportunities.
- Identify high-demand AI skills.
- Explore salary trends.
- Analyze job openings and applicant competition.
- Understand company hiring patterns.

Key Activities

1. Data collection
2. Data cleaning
3. Exploratory Data Analysis
4. SQL analysis
5. Dashboard development
6. Business insights
